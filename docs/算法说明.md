# 八字排盘软件 · 算法说明（第一阶段文档）

> 版本：v1.0（2026-10-27）
> 范围：技术架构、历法库选型、四柱/节气/时区/真太阳时/大运算法、流派差异规则清单、测试计划与结果、风险点。

---

## 1. 技术架构

**总体分层**（自下而上）：

| 层 | 模块（js/engine/） | 职责 |
|---|---|---|
| 数据表层 | constants / hiddenGan / nayin / xunkong | 干支、五行、阴阳、藏干、纳音、旬空的独立常量表 |
| 规则推演层 | ganzhi / wuxing / shishen / changsheng / tigerDun | 六十甲子运算、生克、十神、十二长生（双流派）、五虎遁/五鼠遁 |
| 历法层 | js/vendor/lunar.js（lunar-javascript） | 农历、节气精确交接时刻、干支日序、八字基准、起运基准 |
| 时间校正 | solarTime | 平太阳时（经度差×4分）、真太阳时（+均时差近似） |
| 编排层 | rules / daYun / chart | 规则快照、大运编排（方向与折算解耦）、主引擎统一输出 |
| UI 层 | index.html + css/app.js | 录入、排盘、设置、记录管理（浏览器本地） |

**工程形态**：原生 HTML/CSS/JS，无构建工具，浏览器 `file://` 直接打开即可运行；全部引擎模块为 UMD（浏览器挂 `BaziCore.*`，Node 可 `require` 供 `node --test` 自动化测试）。核心排盘在本地完成，不上传任何个人信息；排盘记录存浏览器 localStorage（仅本机）。

## 2. 历法库选型

选用 **lunar-javascript**（6tail，MIT，单文件无依赖，约 435 KB，可离线）：
- 内置天文算法：公农历互转、闰月、二十四节气**精确交接时刻**（分钟级）、干支日序（经长期维护的算法）、八字（年柱立春/正月初一双口径、月柱节令制、日柱早/晚子时双 sect）、大运（顺逆+起运折算双口径）、真太阳时接口。
- 与本项目「准确性优先、可复现、离线」要求匹配；核心历法计算不自研、不硬编码、不依赖在线接口。
- 库内字符串为 i18n 占位符存储，调用 getter 返回中文；本项目引擎层直接使用中文字面量，不受影响。

## 3. 四柱算法

统一从单一历法对象生成，四柱共用同一 `Lunar`/`EightChar`（注意 `getEightChar()` 有缓存，全程只取一次并 `setSect`）。

### 3.1 年柱
- **立春年界（默认）**：`EightChar.getYearGan/getYearZhi`（`getYearInGanZhiExact` 口径），按立春交接**时刻**判定，非按公历日期。
- **正月初一年界**：`lunar.getYearGan/getYearZhi`（`getYearInGanZhi` 口径）。
- 年界切换会真实改变年柱干支。

### 3.2 月柱
- 一律按**节令**（十二节：立春/惊蛰/清明/立夏/芒种/小暑/立秋/白露/寒露/立冬/大雪/小寒）交接时刻判定月支归属（`getMonthInGanZhiExact`）。
- 月干按年干五虎遁推（甲己丙作首…），库已内置；**正月初一年界且与立春年不同时**，月干按所选年干用本引擎 `tigerDun.monthGanOf` 重推，并标记 `monthGanRecomputed`。
- 农历月份/公历月份**不**直接决定月柱。

### 3.3 日柱
- 干支日序由历法库可靠算法给出（以儒略日换算），不经随意参考日期或固定偏移量。
- 日界（换日）规则映射（经源码与实测确认）：
  - `23:00 换日（晚子时算次日，默认）` → 库 sect=1 → `getDayGanExact`（23:00–23:59 日干+1）；
  - `00:00 换日（晚子时算当天）` → 库 sect=2 → `getDayGanExact2`。
- 早子时/晚子时概念在界面按规则显式标注，不与时辰归属混谈。

### 3.4 时柱
- 时辰地支归属：子=23:00–00:59、丑=01:00–02:59 … 亥=21:00–22:59（与库 `getTimeZhiIndex` 一致）。
- **时干口径（本软件自洽约定，已文档化）**：按所选日界下的日干，以五鼠遁（甲己还加甲…）推时干。
  - 默认 23:00 换日规则下与库口径一致（库 sect=1 时干亦按次日日干推）；
  - 00:00 换日规则下，本软件时干按当天日干推（库该模式下时干仍按次日推，属流派差异，见「待验证项」）。界面「排盘依据」会说明此口径。

## 4. 节气、时区与真太阳时

- 节气：历法库提供全年 24 节气精确交接时刻；月令展示取 `getPrevJie/getNextJie`。
- 时区：默认 UTC+8（标准经线 120°E），可在规则中修改；标准经线 = 时区偏移小时 × 15°。
- 时间校正（可配置，默认不校正）：
  - **地方平太阳时** = 钟表时 + (出生地经度 − 标准经线) × 4 分钟/度；
  - **真太阳时** = 平太阳时 + 均时差。均时差用常见近似公式（NOAA 风格）：B=2π(N−81)/364，EoT(分)=9.87·sin2B − 7.53·cosB − 1.5·sinB。
  - **精度声明**：近似公式误差约 ±1–2 分钟；更高精度需天文历表（列入待验证项）。
  - 选校正而未提供出生地经度 → 引擎返回 `NEED_LONGITUDE`，界面拦截并提示，**不假装已完成校正**。
  - 界面同时展示原始时间、校正后时间及依据（经度/标准经线/均时差分钟数）。

## 5. 大运算法

**排运方向与起运折算分离**（均记录当前所用规则）：

- **方向**：年干阴阳（以所选年柱为准）× 性别 → 阳年男、阴年女顺排；阴年男、阳年女逆排。
- **起运折算**（距最近节气的时刻差，3天=1年、1天=4个月、1时辰=10天）：
  - `hour`（默认，时辰级近似·传统）：时辰差折算，与库 sect=1 口径一致（含「整点 23 时按亥计」的库约定）；
  - `minute`（分钟级精确）：按分钟精确折算，与库 sect=2 口径一致。
- 起运公历时刻 = 出生时刻 + 起运偏移（年/月/日/时），虚岁 = 起运年 − 出生年 + 1（以公历出生年计，已文档化）。
- 大运干支以月柱为基准顺/逆推 10 步，每步展示干支、起止公历年、虚岁区间。
- 节气交界附近出生者起运差可能为 0 天级（时辰差折算），界面与说明中如实呈现。

## 6. 流派差异规则清单（均可配置，界面显示当前规则）

| 规则 | 选项 | 默认 | 影响 |
|---|---|---|---|
| 年柱年界 | 立春 / 正月初一 | 立春 | 年柱干支、月干重推 |
| 日界 | 00:00 换日 / 23:00 换日 | 23:00 | 晚子时日柱归属、时干 |
| 时间校正 | 不校正 / 平太阳时 / 真太阳时 | 不校正 | 使用时刻、四柱（临近交界时） |
| 十二长生 | 阳生阴死 / 同生同死（木亥火寅金巳水土申） | 阳生阴死 | 十二长生排布 |
| 大运起运折算 | 时辰级（传统）/ 分钟级 | 时辰级 | 起运年月日时 |
| 时区 | UTC+8 等 | UTC+8 | 标准经线、校正 |

同一排盘记录保存时**附规则快照**（`rules.snapshot`），防止日后设置变化导致历史结果无法复现。
