# 八字排盘（BaziApp）

一款**本地运行的中文四柱八字排盘 Web 工具**：录入出生信息，按可配置的流派规则真实计算并展示四柱、十神、藏干、纳音、十二长生、旬空、五行分布与大运。

- 排盘计算完全在本地浏览器完成，不上传任何个人信息；排盘记录仅保存在本机浏览器（localStorage）。
- 命理内容属于**中国传统文化体系**，界面与文档均明确声明：不构成科学证实的预测结论。

## 二、运行方式

**方式一（推荐，零依赖）**：直接双击打开 `index.html`（浏览器 `file://` 即可运行；全部脚本为相对路径本地文件，无 CDN、无 fetch、无构建）。

**方式二（本地 http 服务）**：任选其一
- `python -m http.server 8080`（在 bazi-app 目录），浏览器访问 `http://localhost:8080`；
- 或 Node：`npx serve .`（需联网装包）。

## 三、依赖与安装

- 运行时：无任何第三方依赖。历法库 `js/vendor/lunar.js`（lunar-javascript，MIT）已随项目内置。
- 自动化测试：需要 Node.js ≥ 18（自带 `node --test`）。本项目开发环境 Node v22.23.2。

## 五、排盘规则与默认值

| 规则 | 默认 | 可选项 |
|---|---|---|
| 年柱年界 | 立春 | 立春 / 正月初一 |
| 日界（子时） | 23:00 换日（晚子时算次日） | 00:00 / 23:00 |
| 时间校正 | 不校正 | 不校正 / 平太阳时 / 真太阳时 |
| 十二长生 | 阳生阴死 | 阳生阴死 / 同生同死 |
| 大运起运折算 | 时辰级（传统） | 时辰级 / 分钟级 |
| 时区 | UTC+8 | UTC-12 ~ UTC+14 |

- 修改规则会**真实重算**命盘；每条规则在界面附「影响」说明；历史记录保存生成时的**规则快照**，点开记录按原规则复现。
- 流派差异与未确认口径见 `docs/待验证项.md`，均不作已确认结论；界面「排盘依据」可展开查看本盘实际采用的规则与口径声明。

## 六、已实现功能清单（对照需求）

- 出生信息录入：姓名备注 / 性别 / 公历或农历（含**闰月**勾选）/ 精确到分 / 出生地（名称 + 经度）/ 时区 / 时间校正三档；输入不合法给出明确提示。
- 历法转换：公历↔农历（库级天文算法），农历输入展示换算后信息供确认；八字月柱按节气计算，绝不把农历月当八字月柱。
- 四柱：年（立春 / 正月初一可配）、月（节令制 + 五虎遁）、日（干支日序 + 日界规则）、时（时辰归属 + 五鼠遁自洽口径）；交界警示（距时辰整点 ≤5 分钟）。
- 时间校正：平太阳时 = 经度差 × 4 分/度；真太阳时 += 均时差近似（NOAA 风格）；显示原始 / 校正后时间与依据；缺经度则**拦截并提示**，不假装校正。
- 十神：以日干为基准的完整 10 神矩阵；日主与其他天干区分显示。
- 藏干：十二支本 / 中 / 余气独立数据，每藏干附十神。
- 五行：四柱八字 / 天干 / 地支本气 / 藏干 **四口径分开统计**（简单计数，已注明不计权重），仅描述结构不作旺衰喜用结论。
- 纳音 / 十二长生（双流派可配）/ 旬空：独立完整数据表 + 完整性测试。
- 大运：方向（年干阴阳 × 性别）与起运折算分离；起运年/月/日/时 + 公历时刻 + 虚岁；10 步大运表（干支 / 年份 / 虚岁），含「出生至起运前」段；所用规则在结果页说明。
- 结果页：四柱横排（桌面 4 列 / 移动 2×2），日主视觉强调；五行色仅作辅助、信息不依赖颜色；「排盘依据」可展开；复制排盘文字 / 浏览器打印（含打印样式）/ 保存历史记录 / 清空。
- 历史记录：localStorage 本地保存（≤100 条），记录含规则快照，点击按原规则重排复现。
- 双端可用：桌面与移动端截图自检通过（见 `_shots/`）。

## 七、部署说明

纯静态站点，可部署到任意静态托管（如 Nginx / GitHub Pages / 对象存储）：将整个 `bazi-app/` 目录原样上传即可，无需构建。数据仍保存在访问者本机浏览器，不上传服务器。

## 八、未实现 / 限制（如实声明）

- 神煞、流年、流月：未实现（需求定位为后续扩展）；引擎 `chart` 结构已按「可扩展」设计，新增字段不破坏现有输出。
- 时间校正的均时差采用近似公式，误差约 ±1–2 分钟（见待验证项 #1）。
- 「同生同死」流派中土长生位按水土同宫（申）实现，另有派别取寅（待验证项 #2）。
- 大运时辰级折算中「整点 23 时按亥计」为 lunar-javascript 的约定口径（待验证项 #3）。
- 00:00 换日规则下时干口径与本软件自洽口径一致（按当天日干五鼠遁），与部分软件按次日推时干的口径存在流派差异（待验证项 #7），界面已声明。
- 跨时区极端样张（UTC±0 等）尚未做交叉验证（待验证项 #4）。
- 出生时间交界（≤5 分钟）仅提示，不改写用户输入。
